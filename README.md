# Orçamentos — Marcenaria

Sistema de orçamentos para marcenaria com dashboard, cadastro de materiais e clientes e calculadora de custos.

🔗 **Demo:** https://bertmartins.github.io/carpentry-project/

## 🛠️ Tecnologias

- HTML
- JavaScript

## 🚀 Como executar

```bash
git clone https://github.com/BertMartins/carpentry-project.git
cd carpentry-project
```

Abra o arquivo `index.html` no navegador ou acesse a demo acima.
